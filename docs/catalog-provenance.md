## Supported facts and role-specific limitations

### Data Analyst — direct

**Supported facts.** The UK Civil Service Government Analysis Function profile says data analysts collect, organise, and study data to provide business and operational insight. It lists managing, cleaning, abstracting, and aggregating data; linking datasets; data-quality checking and cleaning; using data-analysis and data-visualisation tools; presenting conclusions clearly; and potentially making recommendations about data use.

**Limitations and catalogue guidance.** This is an official UK Civil Service/Government Analysis Function role profile, not a universal occupational classification, and it supplies no occupational code. The direct mapping is to the exact title **Data Analyst** in this source, but the profile is a government analytical-role framework and may not represent every private-sector Data Analyst job. It does not validate catalogue requirements, seniority assumptions, match scores, or technologies. Non-standard or overlapping titles such as AI Engineer, Machine Learning Engineer, Full Stack Developer, and Cloud Engineer require separate authoritative occupational evidence; this profile must not be used as evidence for them. Use source-stated responsibilities and skills as occupational evidence only; catalogue skill lists, recommendations, weighting, and match-score logic are separate design decisions not stated or validated by the source.

### Data Scientist — direct

**Supported facts.** O*NET states that Data Scientists develop and implement techniques or analytics applications to transform raw data into meaningful information using data-oriented programming languages and visualization software. It describes data mining, data modeling, natural language processing, and machine learning applied to large structured and unstructured datasets. Listed tasks include analyzing large datasets, creating graphs/charts or other visualizations, and testing, validating, and reformulating models for accurate prediction of outcomes of interest.

**Limitations and catalogue guidance.** This verifies the official occupational profile and its stated tasks, activities, and software examples; it does not validate any catalogue-specific skill taxonomy, proficiency thresholds, recommendation logic, or match scores. Occupational profiles describe a broad occupation, so an individual job posting may differ. AI Engineer, Machine Learning Engineer, Full Stack Developer, and Cloud Engineer are non-standard or variably scoped titles; this Data Scientists profile is not an exact mapping for them, nor evidence of their specific requirements or scores. A broad analogue, if used, would not establish direct equivalence. Treat the facts as source-stated description/tasks, not catalogue-design recommendations.

## Shared scope and publication note

These government/official occupational pages are **broad descriptions**, not validated CareerInsight AI input weights, guaranteed job requirements, local vacancies, or employment outcomes. A **direct** fit means the source title is the exact catalogue role, except Data Engineer, where the official occupation profile explicitly lists “Data Engineer” as a sample reported title. An **analogue** fit means **no direct occupation-title match was verified** and the cited profile is retained only as a closest official reference; it must not be overstated as a full-stack, cloud, AI, or machine-learning job-taxonomy match. Catalogue skills, weighting, proficiency thresholds, recommendations, ranking, and match-score logic remain separate design decisions requiring their own validation.
